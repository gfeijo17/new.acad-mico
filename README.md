# Buscador do Google Acadêmico 🎓

Aplicação web desenvolvida em Python (Flask) que realiza buscas no Google Acadêmico, retorna os 10 primeiros resultados relevantes e disponibiliza o link de download direto em PDF quando disponível.

## 🚀 Tecnologias Utilizadas
- **Backend:** Python 3, Flask, Gunicorn
- **Scraping / Busca:** Scholarly
- **Frontend:** HTML5, CSS3, JavaScript (Fetch API)
